## What `/banking` is now
- Header: "Banking review", account select (bank accounts, `Chase Total Checking ••4321`), explicit range "Oct 1 – Oct 14", presets This week / This month / Last month, "Synced 1 hour ago".
- Summary (account's own): Balance (as-of), Money in, Money out, Balance check, Review inbox.
- Balance check = `balanceTie`: "Ties to bank" / "Off by $X" (bad tone) / "Not checked yet". Never mixed with the inbox.
- Review inbox = `reviewInbox.badgeCount`: "N to review this month" or "Review inbox clear"; real scope in the `?` tooltip; links to `/review`.
- **Not in the plan** (open): Unmatched · Different amount · Different date · Marked not in plan · Not sure. Count + net + one line each.
- "Unmatched, by kind" chips (Spending, Card payment, Debt payment, Transfer, Income, Refund, Other) + "Card and debt payments are not overspending."
- Rows for the picked bucket (first non-empty if none): date, name, amount, Pending, category or "No category", chips (Unplanned allowance, Reimbursable, and the reason on Not sure), plan line "Planned $40.00 on Oct 2 → paid $300.00 on Oct 4 (+$260.00 / 2 days late)".
- Paging: server `bucket` / `cursor`, 25 per page, "Show more". One query per page.
- **Planned this period** (collapsed): label, due, planned, fate in words, matched amount/date.
- **All accounts · this week** (last, small): counts toward weekly plan, plan or "Plan not set", link to `/spending/week`.
- `reconciliation.unexplained != 0` shows "Some rows couldn't be placed: $X".
- Non-forecast account: line "H2 plans from one account. Rows here are listed as 'Not sure'."

## URL state
- `?account &from &to &bucket &kind` via `useUrlState` (replaceState), so Back from a register returns to the same view.
- Defaults write nothing. A future or reversed range falls back to this month (the API would refuse it).
- Dashboard tile link `?account=<plaid_accounts.id>` is the same param.
- Row link = the one route rule `txnRoute()`: Chase checking is `/transactions?account=<id>&month=<YYYY-MM-01>&tx=<id>`; other banks go to their account page; accounts not yet loaded render the row unlinked.
