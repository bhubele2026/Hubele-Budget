## Items
- Badge: `GET /categorization/review/count`; key `[...listKey, "count"]` so queue invalidations hit it.
- Banking: summary asks `rowsPerBucket=25`; the default bucket renders from it (one call).
  - "Show more" fetches page 1 (for the cursor) on hover/focus/click; later pages as before.
  - Kind filter still pages from the server.
- Amex:
  - Band reads owed + purchases from the single `accountId=all` summary (`scope.cards[]`); no per-card summaries.
  - `/amex/anchor` is not called where the summary is on; `summary.owed` feeds the anchor (kept across month changes).
  - Head, band, summary render before the month's rows; only chart + ledger show a skeleton.
  - 12-month pull starts near the chart (IntersectionObserver); chart says "Loading the last 12 months…".
  - `/plaid/environment` loads on press.
- Landing warm-up: waits for no queries in flight + 400 ms quiet + idle callback; gives up at 15 s.
- Chase register: 365-day cash signal waits for the chart; chart says "Loading the forecast line…".
- Prefetch map: `lib/warmRoutes.ts`; hover, focus, pointer-down, touch-start on layout, ribbon, phone nav, dashboard tiles.
  - Banking review + plaid items; Chase first ledger page; Amex all summary + month rows; Spending period + items; Forecast 90 + cash-signal 90; Debt debts + avalanche settings + extra.
  - Removed: `/api/dashboard` warm, 1,000-row 3-year ledger warm.
  - Links that carry a query (a card, a month) warm the chunk only, except Banking `?account=`.

## Deviations / doubts
- Trend still loads at once when it feeds a figure: a past month, a card filter, an empty current month (first-load jump), or a computed/missing anchor. Only the plain "this month, all cards, real anchor" case defers.
- Banking summary now carries up to 125 rows (5 buckets x 25); server cost per call is a bit higher, one call fewer.
- `ledger-columns` header colour neutral-400 to neutral-600 (axe contrast fail revealed once the page rendered earlier). Visible, tiny.
- Plaid "Connect" button is no longer disabled when unconfigured; a press says why instead.
