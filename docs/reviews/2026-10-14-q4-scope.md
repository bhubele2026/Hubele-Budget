# Q4: no stale number under a new scope (branch prem/q4-scope, from prem/integration 02e53e3a)

Web only. No API, spec, schema or codegen change. All fixtures synthetic.

## The bug
- App-wide `placeholderData: keepPreviousData` hands a query the last key's answer.
- Pages drew it under the new heading: All cards owed under "Platinum", last week's figures under this week's title.
- The owner gate said "Only the household owner..." while `/me` loaded.
- Category pickers said "Unknown" while the list loaded.

## What changed

### `scoped()` (lib/queryState.ts)
- `scoped(query, matches)` returns `{ data, previous, isSwitching }`.
- `data` only when the answer matches the asked scope and is not a placeholder.
- `previous` holds the old answer; no screen draws it unlabelled.
- `amexSummaryMatches`: card (`scope.accountId`, null = all) + days. A `from` moved to the tracking start counts only when `limitations` says so.

### Amex (pages/amex.tsx, amex-card-band.tsx)
- Summary + Needs attention + All-cards balance list use scoped data; loading skeleton, same height.
- `owedRef` written in render is gone. Owed kept per card in state (effect), read only for the same card.
- Per-card anchor: `placeholderData: undefined`.
- Month rows and 12-month rows: a placeholder is not this month's rows.
- Month change shows "Loading <Month>..." (`amex-month-loading`), never "No transactions match these filters".
- Band purchases use scoped data (no old period under the new label).
- Card choice (band click) pushes ONE history entry, like the section tabs. Self-heal to All cards replaces.
- Embedded ledgers on `/next/accounts/:id` have `key=` by account (no previous card's anchor).

### Spending (spending/PeriodView.tsx)
- Breakdown scoped by `start` + `period`. Old week's figures never sit under the new title; "This week" label cannot come from old data.
- Household budget scoped by `monthStart`.

### Banking (command-center.tsx, banking/BucketRows.tsx)
- Review scoped by key + echoed `period.to`. Dropdown value, balance, buckets, seeded rows come only from this scope.
- "Show more" answer that lands after the scope changed is dropped.

### Chase (transactions.tsx, transactions/useChaseLedger.ts)
- The ledger hook withholds another filter's rows, counts and balances (`rows` empty, `first` undefined while placeholder).
- Page keeps its chrome and says "Loading..." (`chase-switching`); cold first load still shows the page skeleton.
- Reviewed count, balance-unavailable, trend balance, pending and after-today lists all follow.
- Account is `useUrlState` (`push: true`): one history entry per pick, Back/Forward restores, `history.state` kept (no `replaceState(null)`). Saved-pick self-heals replace.

### Owner gate (hooks/useOwner.ts)
- `useOwner()` -> `true | false | "unknown"`. Unknown draws a same-size placeholder; denial only on false.
- Used by PeriodView -> PlanPrompt, WeekPlanPanel, WaysBackSheet, amex-pay-mode.
- `/me` failure -> `true` (controls show, server refuses a member). Same as before.
- `/me` prefetched in the shell (`ProtectedShell`, key `getGetMeQueryKey()`).

### Category words (lib/categoryLabel.ts)
- None -> "Uncategorized"; list loading -> blank/skeleton; found -> name; loaded but missing -> "Deleted category".
- CategoryPicker (takes `undefined` = loading), review-categories, TxnTable rows (Accounts, Activity panel).
- Categories warmed with the Chase and Amex routes (lib/warmRoutes.ts).

### Stale promises
- AffordSheet: each check takes a ticket; input change or close invalidates it.
- BucketRows cursor (above).

### History and scroll
- `useUrlState`: `push` option and per-call `{ replace: true }`; new `pushUrlParam`.
- Scroll restore waits for current-scope data (`pageDataPending`: a mounted query on a placeholder, or with no data yet and fetching) as well as height.
- Give-up 1.5 s -> 4 s. A background refresh does not hold a restore.

### Budget and Bills
- Previous month's figures stay (no blank) but are said to be that month's: "Showing <Month> while <Month> loads".
- Budget "Every figure ... for <Month>" line follows the data's month.

## Figures that move
- None. No number is computed differently. Numbers that used to show under the wrong scope now show a skeleton until their own answer lands.
- Before -> after on the preview household (rich2), Platinum asked while its answer is out:
  - Summary under "Platinum": $2,952.85 (all cards) -> skeleton, then $2,340.55.
