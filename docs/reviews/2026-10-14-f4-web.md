## What changed
### This week / Monthly allowance
- Headline = KNOWN (`known`, `remaining`, `over`). `provisional` → "Provisional" chip + "Unconfirmed $X may change this · <row> — bank says loan payment".
- Over cell reads "Over so far" when provisional (never the bare "Over").
- Three groups: Counts toward plan · Payments & transfers (not spending) · Unconfirmed (evidence + "Not counted yet: …").
- Unconfirmed links to Proposed fixes (`/banking?fixes=1`).
- "Why over?" gets one summary line from server figures ("Over $X · Cat $Y so far vs usual by Oct 14 $Z · plan $P").
- "usual by Wed" (week) / "usual by Oct 14" (month); `full_period` says "usual for a full week/month".
- Under Details: "A full month is usually" per category (`usualFullPeriod`), and Unconfirmed / safe-to-spend lines.
- "Above usual" chip is the warning token, not red. "transactions", not "purchases".
- Named **Monthly allowance** on the tile, page title and nav tab.
### Dashboard tile
- Lazy `WeekKnownTile` (own chunk) reads the breakdown; spine-based tile shows until it lands. Chip "Provisional"; line "Over $X so far · provisional".
### Plan activation
- Dialog runs the dry run first; per Saturday "Weekly Spend reserve $before → $after = card purchases + carried + left to spend" (+ "already paid" when not zero, so parts add to the cent); low point before → after.
- Set plan disabled until the dry run is in; `allowed:false` shows the server reason, button off; dry-run failure says so.
- WeekPlanPanel and Allowances overrides show the 409 `plan_unsafe` reason (panel keeps it and disables Save).
### Amex
- "How this card is paid" (In full weekly/monthly · Paying down (minimum + extra)), source, owner-only Change through a confirm dialog (`PUT …/payoff-mode`). Never auto-set.
### Forecast line
- "Weekly Spend: card purchases $A (+ carried $C) + left to spend $B"; no plan keeps "Weekly Spend reserve $X · no weekly plan set".
### Banking review
- Direction-aware words; variance is the big number on difference rows; bucket cards show Income / Bills variances apart with effect on cash.
- "Filed as Dining & Coffee — looks like income" + Categories link.
- Balance check on `balanceCheck` (old `balanceTie` no longer read): Matches bank · Off by $X + direction + Investigate (balance explain popover) + Open register · Resolved since · Not checked yet + reason · stale greyed "Checked N days ago — Sync to recheck".
- Placement banner: "H2 could not place some rows" (testid `br-unplaced`).
- Proposed fixes disclosure (read-only, fetched when opened).
### Ways back
- "usually" → "usual by Wed" (from `usualThrough`), "usual for a full week" otherwise.
