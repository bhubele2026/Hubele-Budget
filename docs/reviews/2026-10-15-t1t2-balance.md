## Deviations
- `bankCheckLedger` returns `counted[] {id, contribution, late}` instead of `countedIds: string[]` (the investigation needs each row's contribution and whether it arrived late).
- `verdict` is also `null` when there is no difference to explain (matches / not checked).
- "as of" says the reading's day ("as of Oct 15"); the reading line carries the time.
- "Why this number?" had no live entry point once "Investigate" became "Review difference" (its other caller, SummaryRow, is not mounted): it now sits on Banking's H2 balance cell.
- The Forecast page offers no Sync button (its tests mock the client module without the Sync hook): no reading + a linked checking account → the existing "Link a checking account" picker reads the bank; none → "Link a bank" (Settings).
- `ForecastPanel.tsx` (dashboard chart legend): one tone change (rust only below zero) — the T2 rule; T3 still owns its HORIZONS.
- Chart `linear` was done here (design §c) rather than in T3.
