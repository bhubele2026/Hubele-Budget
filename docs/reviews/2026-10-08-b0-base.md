## Identity rules (`lib/accountIdentity.ts`)
- `identityOf(account, { cardOrder? })` returns `{ id, kind, label, shortLabel, mask4, accent, isCard }`. `kind` is checking, savings, amex, card, loan or other.
- Credit type, or a credit-card subtype, makes a card. It is Amex when the institution slug or name contains "amex" or "american express".
- Checking gets the checking accent. Amex gets `amex`. Savings, loans and unknown accounts get `other`.
- `cardOrderOf(accounts)` lists non-Amex card ids by first appearance. The first card gets `card2`, later ones get `other`. Only two non-Amex accents exist, so a third card shares `other`. Its label and mask still tell it apart.
- `label` is institution plus name with duplicate words removed ("Chase Total Checking"). It falls back to a kind word and is never empty. `mask4` is the last 4 digits, or "" when there are none.

## Primitives (`components/next`, import from `@/components/next`)
- `PageGrid({ children, className? })`
- `Panel({ title, sub?, accent?, actions?, to?, span?: 3|4|6|8|12, className?, children })`. `to` makes the title a link.
- `StatBlock({ label, value, delta?, hint?, tone?: "neutral"|"ok"|"bad" })`. A number `value` is formatted as money; a signed `delta` is printed with its sign.
- `AccountChip({ identity, size?: "sm"|"md" })`. It shows an accent dot, the label and `••mask4`; `sm` uses the short label.
- `TxnTable({ rows, dense? })`. Each row is `{ id, date, description, amount, identity, pending, category?, href? }`. Rows are 36 px (40 px when not dense) and show a chip on every row, a Pending/Posted word and a separate Category column. A row with an `href` is focusable and opens on Enter or click. `shortDate()` is timezone-proof.

## How to add a panel
Put your page in `pages/next/<Name>.tsx` (default export, already routed and lazy). Wrap the content in `<PageGrid>`, then add `<Panel title=... span={6} accent={identity.accent}>` for each block. Put figures in `StatBlock`s, rows in `TxnTable`, and label every account with `AccountChip` built from `identityOf(acct, { cardOrder })`. Compute `cardOrder` once with `cardOrderOf(allAccounts)`. Use tokens only, with no palette utilities or colour literals. Do not edit `App.tsx`, `routePrefetch.ts`, `routes.test.tsx` or `index.css` for routing or tokens; if you need a new token, add it next to the `acct-*` block.
