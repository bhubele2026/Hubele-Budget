## The page now

- **Grid:** `PageGrid` (12 / 6 / 1 columns), one account experience for `/transactions` and `/next/accounts/:id` (checking).
- **Head (span-12):** h1 "Chase" + logo (unchanged role and text), the account's `AccountChip` under it (checking accent, "Chase Total Checking ••5526"), Add / Sync / Connect on the right. Embedded: the actions row only (the account page owns the title).
- **Controls row (span-12):** Wk/Mo/Yr + range label + month navigator (Mo); account picker (2+ Chase accounts); the "Match N items in Review" chip.
- **Figures:** "Money in vs out" and "Checking balance" as checking-accent `Panel`s, span-6 each (span-4 each beside a host's `lead` panel). Inner markup unchanged (the stats tests read it).
- **Household spending strip (span-12):** the shared `ChaseInsightStrip`, no account accent (it is every account's, CH-15).
- **Trend chart:** `BalanceTrendChart` is now a span-12 panel: caption as title, range + collapse control in the head, legend (Actual / Forecast / Today), body 220 px phone / 260 px md+ (was 140 px), ticks 11 px.
- **Ledger:** one `LedgerPanel` (span-12, `sticky-safe` + `flush` + `static`, checking accent). Its pinned pane holds the review controls (to review, select page, hide reviewed, freshness) and sticks to the top of `<main>`; the page publishes the pane height as `--page-sticky-top`; the bulk bar and day heads stick under it.
- **What stopped sticking:** the old page pinned the whole top (head, range, both stat cards, chips): about 450 px on a 390 px phone. Now only the ledger pane sticks (49 px desktop, 93 px phone, measured).
- **Motion:** `rise(i)` (`tile-in` + `--stagger`) on the two figure panels and the strip. Never on the ledger panel (it hosts the sticky stack). Reduced motion is the existing kill.

## E2E specs (policy: repaired here, a stale spec is never a parity check)

**Not run.** The suite needs real Clerk keys, and there are none locally. Instead:
- every test id a repaired spec reads was checked against the source;
- the repaired selectors were driven in a headless harness: the real page, a fake API, the built CSS.
  - The harness lives in the scratchpad and is not committed.
  - Driven: the row picker, the Remember box, search, options, `option-ignore`, the row "Select" box → bulk bar, the Edit dialog's rule chip, the dim of a row dated after today.

The nine stale specs (parity §2.6):
- `transactions-amex-ignore-row-dim` (Chase half):
  - the category is now chosen with the row picker and `option-ignore`;
  - the dim class is `opacity-50`;
  - the row is seeded for **tomorrow**: a posted checking row is always in the forecast and always dimmed (CH-37), so only a future row shows the Ignore dim on its own.
- `transactions-bulk-forecast-undo`:
  - rows are selected with their "Select" box;
  - rows are seeded on future days in one month: bulk Send skips posted checking rows, and Remove records "not planned" for them (CH-40), so only future rows exercise the flag write.
- `transactions-bulk-recategorize-preview`, `-undo`, `-inline-category-override`, `-transfer-override` (pass 2), `matched-rule-chip-surfaces`: the category is set with the row picker, with "Remember" unticked, which reproduces the old chip's category-only PATCH (the server's auto-relearn is what these specs test).
- `transactions-pending-categorize`: the row picker reads "Uncategorized" before and the chosen name after.
- `transactions-reset-transfer-override`: the row "Manually set" chip is gone from Chase (CH-64). The spec now pins the Edit dialog hint, which disappears on reset and stays gone after a reload.
- `transactions-transfer-override`:
  - the Transfer pill and its X are gone from Chase (CH-64);
  - a transfer is read from the row's hidden bucket marks (CH-29);
  - pass 1 now asserts that marker and that there is no clear-pill.
- `matched-rule-chip-surfaces`: the old `/dashboard` recent list and reimbursements box no longer exist (`/dashboard` redirects to `/banking`). The spec now covers the two surfaces that carry the chip today: the Edit dialog (rule link / "Manual") and the preview dialog.

The other 16 Chase specs read only ids the page still renders. They also cover:
- the stats panels' legend rows (`legendRow`), whose inner markup is unchanged;
- `data-day-group-key`;
- the h1.
