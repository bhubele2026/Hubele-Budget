Web only. No API, spec, schema or money changes. Figures are the server's, read by generated hooks.

## 1. Amex card tab did not select the card
- Cause: not an id mismatch. All ids are the external Plaid `account_id` (`hs-amex-…`): tabs, `txnRoute`, band, summary query, header chip.
- Cause: `useUrlState` read `?card=` once on mount and on Back/Forward only. A tab or row link is a `pushState` on the same page, so the state never re-read.
- Fix: `hooks/useUrlState.ts` also listens to wouter's `pushState` event and re-reads when THIS param's text changed. A push that leaves the param alone does not touch the state.
- Legacy `?accountId=` still works (fallback unchanged). Cold load unchanged.
- Proof (test): `hooks/useUrlState.test.tsx` (push to `?card=`, push to `/amex`, unrelated push), `pages/amexSummaryPage.test.tsx` "a card tab selects the card" (head chip, band ring, summary query by id).
- Proof (browser): click "Blue Cash ••2002" from `/amex`: header chip "American Express Amex Blue ••2002", Summary Owed $612.30 / Purchases $90.90. Before: ALL CARDS, $2,952.85 / $475.60.
- Shot: `scratchpad/preview/shots/w7/chromium-desktop__amex-card.png`.

## 2. Band and Summary disagreed
- Cause: band tiles read the old weekly-payoff model (non-debt cards only, "combined" balance, "this week").
- Fix: `components/amex-card-band.tsx`. Each tile shows Owed (big) + "Purchases · <period>" from `/amex/summary` for the Summary's own period.
- All tile: `owed.current` and total purchases of the `all` summary. Card tiles, debt-linked Platinum included: that card's summary.
- Dropped: "Combined balance", "$0.00 this week", per-card "this week" charges (all weekly model).
- Kept: % ring, relabelled "cleared this wk" with a tooltip naming the weekly payoff plan. "+ Add to avalanche" kept.
- Band cost: one cached summary query per tile (3 on the fixture), same period as the Summary; the selected tile shares the page's key.
- States: loading = pulse, unknown = "—", never $0.
- Figures that move (fixture, week Oct 11-17): All tile $612.30 / $0.00 this week -> Owed $2,952.85 / Purchases $475.60. Blue $612.30 / $135.50 this week -> Owed $612.30 / Purchases $90.90. Platinum (no balance) -> Owed $2,340.55 / Purchases $384.70. All now equal the Summary for the same scope.
- Proof: `components/amexCardBand.test.tsx` (3 tests).
