# V7 — verified ≠ left unchanged; file everything up to today

Branch `finish/v7-verified` · base `origin/main` 720a3746 · migration `0116_category_decisions_unreviewed.sql`.

## What the reviewer found

- A model suggestion left alone for 14 days was settled as `accepted` (`resolved_via = 'silent'`) and counted toward the model's accuracy record.
- Not reviewing a charge does not show its category is right.
- The owner wants every bank and card charge filed up to today. Nothing in the app could do it: the manual run covers 90 days, the job's catch-up 14.

## Verified vs left unchanged, in plain words

- **Verified** = a person looked at the model's suggestion and accepted or corrected it (in Review, or by filing the charge by hand).
- **Left unchanged** = nobody touched a provisional suggestion for 14 days. It now reads **Unreviewed**: "Left unchanged 14 days. Not verified."
- An unreviewed suggestion:
  - leaves the review queue (so the queue does not grow forever);
  - stays **provisional** on its charge (the charge still says it is not confirmed);
  - counts toward **nothing**: not the 30-verified warm-up, not the 9-in-10 accuracy, not the model's priors.
- Only verified suggestions can earn "Let the model file on its own".

## Decisions and departures

- **`queued` in the run response** used to mean provisional + queue. It now means band `queue` only (no category written: "need a look"), so the result line does not count a provisional filing twice. Neither app read the old field.
- **Backlog model jobs** use their own singleton keys (`cat:<household>:all:<n>`). The everyday key `cat:<household>` throttles to one job a minute, which would drop every chunk after the first (and the first too, if a sync job went out in the same minute). A second click inside the minute is still deduped chunk for chunk.
- **No upper date bound**: "up to today" means every row on record, like the 90-day run, which has none either.
- **Banks loader**: `routes/plaid.ts` was outside the file list, so the view repeats its one-line table read and reuses `isSyntheticPlaidItem` and `autoUpdatesOf` instead of extracting a shared function. `itemId` is the same `itemId` `GET /plaid/items` shows; `name` may be null (the screen says "Bank").
- **An unreviewed row is still an engine guess.** `engineMayWrite` is unchanged: after 30 days a newer rule or memory may re-file it, as before V1 (V1's silent `accepted` had frozen it). A person's filing and a locked row are never touched.
- **Rows V1 already settled** had `category_provisional` cleared. 0116 moves their resolution to `unreviewed` but does not set the flag back (not asked; it is a stored value). If V1 never ran in production there are none.
- **Deploy window**: while the old build still serves, its nightly pass could write `accepted` + `silent` after 0116 ran. Such a row would count as verified until undone. The window is minutes; noted, not coded around.
- **Commit trailer**: the commit carries this session's model attribution (Claude Opus 5.5), not the brief's "Claude Fable 5.1".

## Figures that move

- **Money: none.** No amount, total, balance or budget is read or written differently.
- **The model's record**: suggestions left unchanged 14 days no longer count. A household whose record was built partly on silence shows fewer verified and may lose eligibility until people verify more.
- **The backlog run** writes categories (rules, memory, recurring, inherited, and provisional model answers through the background job when AI is on) on old unfiled charges — exactly what the 90-day run already does, over every date. Spending reports for older months change as those charges get a category.

## What the owner does after deploy

1. Household → Automation → Backlog → **File everything up to today**. One click.
2. Read the result line:
   - **Filed N** — filed outright by your rules, what H2 learned from you, and recurring bills.
   - **Suggested M (provisional)** — filed, but waiting for your look in Review.
   - **K need a look** — no category yet; they are in Review.
   - **J left unchanged** — model suggestions nobody touched for 14 days. Not verified; they count toward nothing until you accept or correct them.
3. With AI on, the model works through what is left in the background; its answers arrive in Review as provisional. The Backlog line ("Unfiled charges: N") shows what is still blank.
4. Bank data shows each bank's last data date and whether automatic updates are on.
