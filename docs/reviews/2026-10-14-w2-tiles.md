# W2 tiles: /home is the tile dashboard again

Branch `fix/w2-tiles`, from `fix/nav-review`. Web only.

## What /home is now
- Header: "Today · Wed Oct 14", per-bank freshness, ONE action (`headerActionOf`), small links: "Can we afford something?" and "Morning text".
- Six tiles (3x2 desktop, 2 columns tablet, 1 phone), then the forecast graph (lazy, 30/90/180, "Open the forecast").
- The header's facts line is gone (room to spend, next bill): the tiles carry them.

## Tiles
| Tile | Numbers | Status | Link |

- Whole-card link (stretched anchor, focus ring), hover/focus `prefetchRoute`, restrained lift, reserved 11.5rem height.
- "Why?" (native details) only on This week.
- Money in/out on Banking omitted: not in loaded data.

## Removed from /home (files kept, per lead)

- Accounts list: `/next/accounts` (All accounts). Upcoming: Forecast overview / Bills. Activity: Banking / Amex pages.
- Per-bank Sync: NOT on `/next/accounts`. It is on the Banking page (`SyncButton` in `command-center.tsx`). No footer control added.

- The forecast panel legend still says "Low point in these 90 days: $X", the same figure as the Forecast tile at 90 days. Left unchanged (brief: unchanged behaviour).
- Enter on a focused tile is the anchor's native behaviour; jsdom cannot press Enter, so the test clicks the focused link.
