# W1 — Navigation shell (fix/w1-nav)

## What changed
- One global bar on every route: Dashboard · Banking · Amex · Spending · Forecast · Debt · More.
- Section tabs in a lighter row under the bar. They never replace it.
- `Dashboard › Section › Tab` line above the page. Phone: one `‹ Dashboard` or `‹ Section` link.
- "Home" is gone as a label. Logo and Dashboard both go to `/home`. `/dashboard` redirects to `/home`.
- New routes `/spending/week`, `/spending/month` (Allowances page under a title). `/spending` redirects to week.
- Ledger view lives in the URL: Chase `month` `mode` `account`; Amex `month` `mode` `card` (old `accountId` still read).
- Scroll restoration for the shell scroller: new push starts at top, Back/Forward restores.
- `txnRoute()`: Amex card rows open `/amex?card=…&month=…&tx=…`; Chase checking rows open `/transactions?account=<rowId>&month=…&tx=…`.

## Figures that move
- None. No money logic touched. Only link targets changed (see txnRoute).

## Link targets that moved (tests updated)
- Amex card row: `/next/accounts/<ext>?tx=&month=` → `/amex?card=<ext>&month=&tx=`.
- Chase checking row: `/next/accounts/<ext>?tx=&month=` → `/transactions?account=<rowId>&month=&tx=`.
- Other linked accounts (savings, credit union, non-Amex card, loan) still open `/next/accounts/<ext>`.

## Deviations and doubts
- `/allowances?view=week|month` does not exist. `This week` / `This month` render the whole Allowances page under a title. W5 replaces them.
- `txnRoute` sends a bank row to `/transactions?account=` only for a Chase checking account whose entry has `rowId`. Other banks keep the account page, which already opens their ledger.
- Chase `category` stays read-only from the URL: the page has no category control, so there is nothing to write back.
- `month` keeps the existing `YYYY-MM-01` form (not `YYYY-MM`) so every old link works.
- Review count: pill is hidden while in Forecast (Reconcile tab carries the count); More > Categories carries the queue count.
- Amex card tabs read the cache only. Open Amex first (or it loads on Amex page visit) and they appear; before that only "All cards".
- Escape on the More menu is Radix behaviour; the test shim renders the menu open, so it is not asserted. Drawer Escape is.
- Not checked in a real browser (no Playwright run): jsdom only. Section row on phone scrolls sideways.
- `/reports/<unknown>` now falls to Spending > Reports (was unmapped).
