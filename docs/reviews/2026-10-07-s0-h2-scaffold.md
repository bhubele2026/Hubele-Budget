# S0 — new web app scaffold: Today v0 at `/`, classic app at `/classic`

Branch `reinvent/s0-h2-scaffold` off `main` `8148f2a1`. Frontend lane, stage S0 of the H2 reinvention
(plan `staged-dazzling-dongarra`, 2026-10-07). No financial calculation, query, route handler or stored value
changed.

## The owner's decision

- 2026-10-07: H2 is reinvented as a fresh app, `artifacts/h2`, served at `/`.
- The old app is frozen and served at `/classic` until it is retired (S6), with a banner saying so.
- New design system "Paper & rule": warm paper, ink, one moss accent, clay for attention; Public Sans +
  Source Serif 4 + IBM Plex Mono; hairline rules, not cards; light only. It replaces the navy/orange
  law for `artifacts/h2` only. The classic app keeps its look.
- Center screen is **Today**. Four destinations: Today · Activity · Plan · Ask (masthead on desktop, dock on
  phone). Only Today is live in S0.
- `/design` ships now for an early veto of the look.

## Figures that move

None. Today reads every figure from `useSpine()` or the generated `useGetSettings()`. The one arithmetic on
screen is the meter's "Over by $x" (spent − limit, both already on screen). Debt % paid rounds with
`Math.round`, as the classic landing does, so the two apps agree.

## Must not change

- The spine's no-balance law: Today renders `debt.payoffPct` only. A test smuggles a balance onto the spine
  and asserts it never reaches the screen.
- Plaid storage keys `h2:plaid:link_token` / `h2:plaid:return_to`: Plaid's registered redirect URI is
  `/plaid-oauth`, which H2 now serves, so a link started in the classic app finishes in H2. Pinned by test.
- Shared localStorage/sessionStorage keys with the classic app, on purpose (one origin, one Clerk session):
  `h2:auth-hint`, `h2:chunk-reload-at`, `h2:version-self-reloaded`.
- Mount order in `webMounts.ts` (classic before H2's catch-all). Pinned by test.
- The reduced-motion override stays unlayered and after the base `:root`. Pinned by test.

## Classic base-path fixes

Changed:
1. `artifacts/h2budget/package.json` — `build` is `BASE_PATH=/classic/ vite build --config vite.config.ts`
   (inline, so Render's `BASE_PATH=/` env cannot override it).
2. `src/pages/plaid-oauth.tsx` — `goBack` strips the `/classic` base from the stored return path. The Link
   button stores `window.location.pathname` (now `/classic/settings`); wouter's `setLocation` is
   base-relative and would have gone to `/classic/classic/settings`. (In practice Plaid returns to H2's
   `/plaid-oauth`, which full-page-loads `/classic/...`; this keeps classic's own page correct too.)
3. `src/components/layout.tsx` — the banner "Classic app — retiring. Back to H2 →", a plain `<a href="/">`
   (wouter's `Link` would turn `/` into `/classic/`). On every classic page, the landing included.

Checked, no change needed:
- wouter `base` = `import.meta.env.BASE_URL` minus slash → `/classic`.
- Clerk `signInUrl`/`signUpUrl`, `<SignIn path>`, `<SignUp>` redirects, `logoLinkUrl`, `logoImageUrl` all use
  `basePath`; `routerPush/Replace` strip it.
- Assets: entry, chunks, CSS and Inter preload under `/classic/assets/…`; favicons rewritten by Vite to
  `/classic/h2-mark.svg|png`; CSS font `url()`s under `/classic/assets/`; the settings `.xlsx` sample uses
  `BASE_URL`.
- Every API call (generated client, `/api/version` poll) stays absolute `/api/...` — correct.
- Only one raw `<a>` in classic (the `.xlsx`); every other in-app link is a wouter `Link`.
- `transactions.tsx` `history.replaceState(window.location.pathname…)` keeps the full `/classic/...` path.

## What the screenshots showed

Headless Chromium against `vite preview` (no Clerk keys, so Clerk never loads), 390×844 and 1280×800:
- `/design`: no horizontal scroll at either width (scrollWidth = clientWidth). Column 720 px centred at
  1280 (x 280–1000), 16 px gutters at 390. All four faces loaded (Public Sans, Source Serif 4, Plex Mono
  400/500). Masthead links show on desktop only, the dock on phone only.
- Fixed: the dock's "soon" items had a third line squeezed into a fixed 64 px, which shrank their icons and
  lifted their labels 4 px above Today's. Items now size to content (one row, all icons and labels aligned).
- Sheet: rises from the bottom on the phone, slides in at 420 px from the right on desktop; Escape put focus
  back on "Open a sheet" (checked in the browser, and pinned by test).
- Focus ring: 2 px moss, 2 px offset, visible on the wordmark.
- `/sign-in`: paper and the serif line "H2 — the household’s money, every morning." centred. Clerk's form
  is absent without keys; its look under the new appearance is unverified (see Residuals).
- Today, via a throwaway local harness (made-up data seeded into the query cache; not committed): loaded,
  stale (badge "Refresh failed · last updated 3 days ago" + Sync note), over ("Over by $55", clay bar) and
  cold (date + skeleton shapes, no figures) all render as specified; the classic row clears the dock.
- Plex Mono notes: its zero is dotted by default and the `slashed-zero` variant changes nothing in the
  fontsource subset (the dotted zero already tells 0 from O). In a mono face the thousands comma takes a
  full cell, so the hero reads "$4,218" with visible space around the comma.

## Residuals

- `pnpm audit --prod` is 3, not 0: `proxy-addr` <2.0.8 (critical, via express), `compression` <1.8.2
  (high), `braces` ≤3.0.3 (high, via http-proxy-middleware; no patched release). All api-server
  dependencies, identical on `origin/main`. Needs its own security-pins package (api-server deps are
  another lane's); S0 adds no advisory.
- Classic Playwright e2e: specs `page.goto("/home")` with absolute paths, which now hit H2. Re-point them
  at `/classic/...` before `E2E_ENABLED` is turned on.

  `pnpm run build && PORT=3098 DATABASE_URL=… node artifacts/api-server/dist/index.mjs`, then

  `screenshots/classic-baseline/{390x844,1280x800}/*.png` (22 per size). Without `CAPTURE_EMAIL` it uses a
  throwaway `+clerk_test` user, deleted after.
- Signed-in Today and Clerk's widgets under the new appearance are unverified in a real browser; first real
  check is on the deploy, through the real sign-in.
- After a classic sign-out Clerk's default `afterSignOutUrl` is `/`, which is now H2 (then its sign-in).
