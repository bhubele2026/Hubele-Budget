# P1 gate: stop waiting for sign-in (perf/p1-gate)

## What changed
- Hint set (`h2:auth-hint`) + Clerk still booting: real routes mount at once, queries fire on the cookie.
- Clerk loads signed OUT: hint cleared, query cache cleared, redirect to /sign-in.
- `/` with the hint redirects to `/home` at once.
- 401 before Clerk settles: not retried by react-query; re-asked once when Clerk reports signed in.
- 500s and other errors: `retry: 1` as before.
- Route chunk for the current URL starts at module load (`prefetchRoute`).
- `lazyWithPreload`: keeps the resolved module, so a loaded page renders with no Suspense.
- Shell holds the routes (layout + skeleton, no Suspense) until the page chunk is in. Removes the ~300 ms retry hold.
- Used for all routes and the dashboard lazies (AmexWeekCharges, ForecastRow, Chart, RecapPreview).
- `/version`: one fetch per load (idle double-check removed). Focus check kept.
- Spine module-scope prefetch only on `/` and `/home`. Other routes: the layout badge asks as before.
