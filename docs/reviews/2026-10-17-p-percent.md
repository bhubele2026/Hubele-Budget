## The defect, traced
The Reports Spending tile and the Spending report agree on the amounts but not on the percent. They divided by different totals.

| Surface | Numerator | Denominator (before) | Uncategorized |
|---|---|---|---|
| Hub tile legend + bar | category total | sum of the top 5 categories shown (StackBar's own sum) | not in the bar; only a "+ $X uncategorized" caption |
| Report: Top category stat | category total | server `pctOfRealSpend` = categorized spend (`realSpend.total`) | excluded |
| Report: pie legend | category total | the same server percent (the "Other" slice summed server percents) | excluded (own banner) |
| Report: pie tooltip | amount only | no percent, no denominator | n/a |
| Report help text | | said "percentages are of categorized spend" | |

On the rich2 fixture (span Sep 16 – Oct 16): top category $2,410.81; tile 70% (of the five shown, $3,463.01); report 68% (of categorized $3,532.01).
Neither used what the help text said for the tile, and neither counted the uncategorized $1,409.44.

| Surface | Numerator (after) | Denominator (after) |
|---|---|---|
| Tile legend, bar tooltip | category total | ALL spending in the span: categorized + uncategorized ($4,941.45) |
| Report top-category stat, pie legend, pie tooltip, bar | category total | the same $4,941.45, named in words |
| Uncategorized | its own row/slice on both, "Uncategorized $1,409.44 29%" | same denominator |
| Refunds | refunds that match a category are already netted off that category and off the categorized total by the server (existing B6 rule) | so the denominator is net of them; help text says so |

One calculation: `lib/spendShare.ts` (`shareOf`, `formatShare`, `spendingShares`, `denominatorWords`, `spanLabel`), source in `lib/reportsAnalytics.ts` (see Deviations).
